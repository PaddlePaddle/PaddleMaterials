# CINN 性能矩阵

[English](cinn_performance.md)

## 结论

在本次测试负载下，79 个具备 CINN 路径的注册权重均完成 eager 和 CINN 测试。
全部权重的 warm 加速比中位数为 2.50x，范围为 0.96x 至 5.15x。

- 全部注册权重均加速的模型系列及其中位数：DimeNet++ MP2018 4.79x、DimeNet++ QM9
  4.38x、MatterSim 3.53x、SphereNet MD17 3.13x、SphereNet QM9 2.87x、SFIN
  2.45x、ComFormer 2.43x、DiffCSP 2.12x、DiffNMR 2.06x、CHGNet 1.96x、MEGNet
  1.66x。
- 部分注册权重加速的模型系列及其中位数：MatterGen 1.19x（13/17 个加速）。

## 测试方法

- 测量源码：PR #332 的 `f5ec186`，于北京时间 2026 年 11 月 16–17 日复测。
  远端工作树中 `ppmat/` 下的 197 个 Python 文件和计时程序已与该版本逐文件核对。
  快照的 Git 元数据记录为 `dd87607` 加工作树修改；测量所用模型版本由文件核对确认。
- 环境：Paddle 3.3.1、NVIDIA A100-SXM4-40GB GPU 和 Intel Xeon Gold 6148
  主机。节点为共享环境，绑定 CPU 核不代表独占 CPU。
- 负载：仓库中的预测和采样示例。结构生成模型采样 8 个原子并执行 2 个去噪步骤；
  DiffNMR 执行 500 步完整反向扩散。
- 计时：模型加载、权重加载和输入转换不计入耗时；每次调用前后均进行 GPU 同步。
  首次 CINN 调用单独记录，warm 数据取紧随首次调用之后的 10 次调用的中位数；
  每次调用重置随机种子。本协议没有另设预热稳定性门槛。
- 执行：每个权重在独立进程中测试。共测试 3 轮，每张 GPU 各跑 1 轮；每轮绑定该
  GPU 所在 NUMA 节点的 CPU 核，逐个串行测试各权重。表中耗时均为 3 轮的中位数。
  每个权重的加速比由分别计算的 3 轮 eager 与 CINN 耗时中位数相除得到；
  模型系列加速比再取各权重加速比的中位数。

| 指标 | 定义 |
| --- | --- |
| 首次 CINN | 首次调用的总耗时，包括初始编译和执行 |
| Warm | 紧随首次调用之后 10 次调用耗时的中位数 |
| 加速比 | `eager warm / CINN warm`；大于 1 表示 CINN 更快 |
| 首调用额外开销估算 | `首次 CINN（s）- CINN warm（ms）/ 1000` |
| 估算回本调用数 | 统一单位后计算 `ceil((首次 CINN - CINN warm) / (eager warm - CINN warm))`；warm CINN 没有加速时记为“无” |

回本估算表示总模型调用次数，依据首次调用的额外开销计算，即比较 `F + (N - 1)C`
与 `NE`，其中 `F` 为首次 CINN 耗时，`C` 和 `E` 分别为 CINN 和 eager 的 warm
耗时；eager 首次调用的额外开销未计入。后续调用原样计时，调用内的编译开销仍保留在
相应样本中；该回本公式没有单独累计后续编译成本。所有估算均使用未舍入的原始耗时，
表中耗时为舍入后的显示值。加速权重数和回本条件依据未舍入值判断；显示为
1.00x 的数值可能略高于或略低于 1。

### 执行历史

最初 474 次 eager/CINN 进程测试中，473 次生成了成功的计时记录。第 1 轮中，
`mattergen_alex_mp20_dft_mag_density_hhi_score` 的 CINN 进程在首次调用完成后，
于后续调用的 CINN 符号形状推导中触发 SIGSEGV（退出码 139）。该权重在另外
两轮首次测试中均通过。三轮结束后，仅在原 GPU 上使用相同代码和计时程序补跑
这一失败项，补跑通过。因此，表格包含来自 475 次进程测试的 474 条有效记录；
原始失败日志已保留。现有堆栈无法确定额外编译的触发原因。

例如，MatterGen CSP 各轮后续十次调用的中位数为 0.151–0.174 s，
最长调用为 111.582–125.573 s，十次调用总耗时为 112.944–127.137 s。
这些长调用保留在原始样本中；表中的中位数不是累计成本指标。
