# CINN 性能矩阵

[English](cinn_performance.md)

## 结论

在本次测试负载下，79 个具备 CINN 路径的注册权重均完成 eager 和 CINN 测试。
全部权重的 warm 加速比中位数为 2.59x，范围为 0.92x 至 5.14x。

- 全部注册权重均加速的模型系列及其中位数：DimeNet++ QM9 4.78x、DimeNet++ MP2018
  4.61x、MatterSim 3.51x、SphereNet MD17 3.04x、SphereNet QM9 2.82x、ComFormer
  2.59x、SFIN 2.43x、DiffCSP 2.40x、DiffNMR 2.14x、CHGNet 2.08x、MEGNet 1.70x。
- 部分注册权重加速的模型系列及其中位数：MatterGen 1.19x（14/17 个加速）。

## 测试方法

- 环境：Paddle 3.3.1、NVIDIA A100-SXM4-40GB GPU 和 Intel Xeon Gold 6148
  主机。
- 负载：仓库中的预测和采样示例。结构生成模型采样 8 个原子并执行 2 个去噪步骤；
  DiffNMR 执行完整的反向扩散。
- 计时：模型加载、权重加载和输入转换不计入耗时；每次调用前后均进行 GPU 同步。
  warm 数据取使用相同随机种子的 10 次调用的中位数，首次 CINN 调用单独记录。
- 执行：每个权重在独立进程中测试。共测试 3 轮，每张 GPU 各跑 1 轮；每轮绑定该
  GPU 所在 NUMA 节点的 CPU 核，逐个串行测试各权重。表中耗时均为 3 轮的中位数。

| 指标 | 定义 |
| --- | --- |
| 首次 CINN | 编译和首次执行的总耗时 |
| Warm | 首次调用之后 10 次执行耗时的中位数 |
| 加速比 | `eager warm / CINN warm`；大于 1 表示 CINN 更快 |
| 编译估算 | `首次 CINN（s）- CINN warm（ms）/ 1000` |
| 回本调用数 | `ceil(编译估算（s）× 1000 / (eager warm - CINN warm)（ms）)`；warm CINN 没有加速时记为“无” |

编译估算和回本调用数使用未舍入的原始耗时计算，表中耗时为舍入后的显示值。
